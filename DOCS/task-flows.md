# User Task Flows

## Scenario 1 – Create an Academic Task
**Goal:** Add an assignment due tomorrow.

```text
Login → Dashboard → Add Task → Enter task details → Save Task → Task Details
```

**Success:** The assignment is visible with its deadline and priority.

## Scenario 2 – Schedule a Recommended Study Session
**Goal:** Plan study time for an upcoming assignment.

```text
Dashboard → Task Details → View StudyPartner Recommendation → Study Planner
```

**Success:** A study session appears in the student's planned schedule.

## Scenario 3 – Track Completed Work
**Goal:** Review academic progress after completing a task.

```text
Task Details → Mark Complete → Progress → Weekly Statistics
```

**Success:** The student can see completed tasks and weekly study information.

## Additional Navigation
```text
Dashboard → My Courses → Add Course → My Courses
Dashboard → Notifications → Task Details
Dashboard → Reminders → Task Details / Study Planner
Profile → Settings → Profile
Settings → Log Out → Login
```
