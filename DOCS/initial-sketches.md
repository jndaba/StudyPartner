# Initial Low-Fidelity Mobile Sketches

## Purpose
Initial sketches establish the basic mobile information architecture before refinement in Balsamiq. They focus on layout, navigation, content hierarchy, and interaction rather than visual styling.

## Sketch 1 – Login
```text
┌─────────────────────┐
│     StudyPartner    │
│  Email [________]   │
│  Password [______]  │
│      [ LOGIN ]      │
│   Create account    │
└─────────────────────┘
```
