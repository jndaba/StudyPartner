# Project Objectives

1. Allow students to manage academic courses and tasks from one mobile application.
2. Help students organize study sessions around assignment and examination deadlines.
3. Provide useful reminders and notifications for important academic activities.
4. Allow students to monitor completed tasks, study hours, and weekly progress.
5. Provide simple adaptive study recommendations based on workload and deadlines.
6. Use clear, touch-friendly mobile interaction patterns suitable for smartphone users.
