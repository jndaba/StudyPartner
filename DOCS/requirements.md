# System Requirements

## Functional Requirements

| ID | Requirement |
|---|---|
| FR01 | The system shall allow students to register an account. |
| FR02 | The system shall allow students to log in. |
| FR03 | The system shall allow students to view a dashboard of academic activity. |
| FR04 | The system shall allow students to add and manage courses. |
| FR05 | The system shall allow students to create academic tasks. |
| FR06 | The system shall allow students to specify task deadlines and priorities. |
| FR07 | The system shall allow students to schedule study sessions. |
| FR08 | The system shall provide notifications and reminders. |
| FR09 | The system shall allow students to mark tasks as completed. |
| FR10 | The system shall display progress and weekly statistics. |
| FR11 | The system shall provide study recommendations based on workload and deadlines. |
| FR12 | The system shall allow students to manage profile and study preferences. |
| FR13 | The system shall allow students to change reminder and notification preferences. |
| FR14 | The system shall allow students to log out. |

## Mobile Usability Requirements
- Controls should be large enough for comfortable touch interaction.
- Important actions should use clear labels.
- Navigation should remain consistent between screens.
- Text should be readable on a smartphone display.
- Forms should minimize unnecessary typing.
- Important deadlines should have clear visual emphasis.
- The system should provide feedback after important actions.
- Users should be able to go back without losing context.
- Related information should be grouped into simple sections.
- The interface should avoid unnecessary visual clutter.
