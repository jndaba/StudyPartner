# StudyPartner – Adaptive Study Planner

## 1. Project Overview

StudySync is a mobile study-planning application designed to help
university students organize academic tasks, deadlines, study sessions,
and progress.

The application provides personalized study recommendations based on
academic workload, deadlines, study preferences, and available time.

## 2. Problem

University students often manage assignments, examinations,
study sessions, and deadlines across multiple platforms.

This can result in:

- missed deadlines
- poor time management
- unbalanced study schedules
- difficulty tracking academic progress
- increased cognitive workload

StudyPartner aims to provide one mobile interface for organizing and
prioritizing academic activities.

## 3. Target Users

The primary users are university students who need assistance with:

- academic task management
- deadline tracking
- study scheduling
- reminders
- progress monitoring

## 4. Key Features

- User registration and login
- Course management
- Study planner/calendar
- Task management
- Deadline tracking
- Adaptive study recommendations
- Notifications
- Reminders
- Progress tracking
- Weekly statistics
- Profile management
- Study preferences

## 6. User Interaction Scenarios

### Scenario 1: Create a study task

Login → Dashboard → Add Task → Save Task → Task Details

### Scenario 2: Schedule recommended study

Dashboard → Task Details → StudySync Recommendation →
Study Planner

### Scenario 3: Track completed work

Task Details → Mark Complete → Progress → Weekly Statistics

## 7. Mobile Interaction Design

The prototype uses:

- bottom navigation
- touch-friendly buttons
- mobile forms
- dropdown controls
- checkboxes
- clear labels
- back navigation
- progress indicators
- notification cards

## 8. Usability Testing

Usability testing was conducted with five representative university
students.

Testing focused on:

- ease of navigation
- task creation
- finding deadlines
- understanding recommendations
- progress tracking
- clarity of labels and controls
